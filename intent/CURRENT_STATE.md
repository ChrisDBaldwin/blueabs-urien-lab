# Current State

## What Works

- Exercise system with built-in curriculum, record-to-exercise capture, mastery tracking
- Always-on training environment (timer, meter, health, stun, dummy management)
- Per-opponent save states with visual character select grid
- Game character select integration (native char select screen with timer freeze and fast-forward)
- Two-tab menu, dual notation, live combo tracker, debug display

## What's Missing

- **Distribution:** No way to get save states or exercises to new users without manual file sharing
- **Content:** Curriculum is incomplete; no defensive exercises; move database has gaps
- **Onboarding:** First-time setup requires manually creating `character_select.fs`
